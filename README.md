# AttendEase – Smart Attendance Management System

## Project Overview

AttendEase is a web-based Smart Attendance Management System developed using the MERN Stack. It helps teachers and administrators manage student information, monitor attendance, and organize class schedules efficiently.

## Technologies Used

- MongoDB – Database
- Express.js – Backend framework
- React.js – Frontend library
- Node.js – Runtime environment
- CSS – User interface design
- JWT – Authentication

## Main Features

1. User Registration and Login
2. Dashboard with Attendance Statistics
3. Student Management (Add, Edit, Delete)
4. Attendance Monitoring (Present, Absent, Late)
5. Attendance History
6. Class Schedule Management
7. User Profile
8. Settings and Password Management

## Installation and Setup

### Backend

```bash
cd server
npm install
```

Create a `.env` file inside the server folder and configure your MongoDB connection and JWT secret.

Start the backend:

```bash
npm run dev
```

### Frontend

Open another terminal:

```bash
cd client
npm install
npm run dev
```

Open the local Vite URL displayed in your terminal.

## GitHub Branches

- `main` – Main project branch
- `front-end` – Frontend source code
- `backend` – Backend source code

## Project Purpose

AttendEase aims to make attendance monitoring more organized, accessible, and efficient by reducing manual attendance-recording tasks.
